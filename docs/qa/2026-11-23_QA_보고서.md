## 7. UX 개선 권고사항

1. **정책 문구 단일화**: 가격(VAT), 금액 확정 시점, 입금 기한, 청약철회를 한 곳(운영규정)에서 관리하고 주문서·상품 탭·공지·이용안내가 그 내용을 그대로 쓰게 하기.
2. **모바일 검색 추가** 및 검색 결과 화면에 검색어 표시, 결과 없음 문구 개선.
3. **재고 UX**: 남은 재고 표시, 수량 상한 제한, 품절/부족 안내 통일.
4. **브랜드 404 페이지**: 한글 안내 + 홈/상품/고객센터 링크.
5. **셀프 주문 관리**: 발송 전 취소 요청, 주문번호가 자동으로 붙는 1:1 문의, 결제수단·입금계좌·취소 이력 표시.
6. **고객지원 강화**: FAQ 신설, 1:1 문의를 비공개로 분리 (또는 비밀글 기본 체크).
7. **상품 상세**: 이미지 확대·다각도 사진, 가격 옆 "1개" 의미 명확화, "무료배송" 표기, "시세 연동 상품" 섹션명 정리.
8. **비회원 동선**: 찜 버튼 노출 후 로그인 유도, "회원 전용 구매" 안내.
9. **계산기**: 정수 연산, 입력 형식·최대값 검증.
10. **중복 클릭 방지**: 장바구니 담기/찜/주문 버튼 요청 중 비활성화.
11. **접근성**: 배너 대체텍스트, 제품문의 페이지 H1, 폰트 일관성.

## 8. 최종 종합 의견

- 탐색 → 상품 상세 → 장바구니 → 주문서 작성까지의 **핵심 구매 동선은 PC·모바일 모두 막힘 없이 동작**함 (장바구니/주문서 영역 성공률 92%). 로그인 접근 제어, 타인 주문 차단, 오픈 리다이렉트 방지, 연락처 입력 검증 등 기본 보안·검증도 양호함.
- 가장 큰 리스크는 기능보다 **정책·가격 안내 문구의 불일치**임 (결제·가격 정책 영역 성공률 17%). 특히 청약철회 정책 충돌과 VAT 표기 충돌은 실제 분쟁 시 회사에 불리하게 작용할 수 있어 **최우선 수정**이 필요함.
- 모바일 검색 부재와 회사소개 404는 수정이 쉬우면서 고객 체감이 큰 항목이라 바로 처리를 권장함.
- 결제(PG)·주문 확정·중복 주문 방지·재고 차감은 실거래 없이 검증할 수 없어 BLOCKED로 남음. **PG 테스트 모드 또는 스테이징 환경을 주시면 이 부분을 추가로 검증**할 수 있음.
