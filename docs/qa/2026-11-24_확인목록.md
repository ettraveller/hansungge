무엇을 왜 고쳤는지는 [2026-11-23_조치현황.md](2026-11-23_조치현황.md) 에 있다.

- 이 목록의 수정분은 `qa` 가지에 있다. **푸시해야 QA 에 올라간다** (2026-11-24 기준 아직 푸시 전).

## 3. 주문·결제 — 보고서에서 검증하지 못한 것 (BLOCKED)

QA 는 테스트 결제라 끝까지 눌러도 된다. **운영에서는 하지 않는다.**

| | ID | 확인 | 방법 |
|---|---|---|---|
| ⬜ | QA-054 | 주문 확정 | 무통장으로 주문 → 주문 완료 화면에 계좌·입금 기한이 나온다 → 주문내역에 생긴다 |
| ⬜ | QA-057 | 테스트 결제 | 간편결제로 주문 → 토스 결제창이 「테스트」로 뜬다 → 결제 → 「결제 금액」으로 주문이 남는다 |
| ⬜ | QA-058 | 결제창을 닫았을 때 | 결제창에서 취소 → 주문이 「결제 대기」로 남거나 풀린다. 재고가 돌아온다 |
| ⬜ | QA-055 | 중복 주문 | 「주문하기」를 빠르게 두 번 → 주문이 한 건만 생긴다 |
| ⬜ | QA-036 | 재고 차감 | 재고가 적은 상품을 주문한 뒤 그 상품의 재고가 줄었다 (관리자 › 상품관리) |
| ⬜ | — | 무통장 자동 취소 | 입금하지 않고 입금 기한이 지난 주문이 「취소」가 된다 (기한을 1시간으로 줄여 놓고 다음 날 본다) |

본인확인이 필요한 QA-019(회원가입), QA-024(비밀번호 변경)와 QA-022(카카오 로그인)는 QA 에서 볼 수 없다. 운영에서 따로 본다.

## 4. 관리자 화면

| | 확인 | 방법 |
|---|---|---|
| ✅ | 자주 묻는 질문 — 적고 저장 | 관리자 › 자주 묻는 질문 → 「+ 질문 추가」 → 묶음 이름·질문·답 → 저장 |
| ✅ | 자주 묻는 질문 — 손님 화면 | /qa/support 에 「자주 묻는 질문」 메뉴가 생기고, /qa/support/faq(/qa/faq 도)에 묶음별로 나온다. 답의 줄바꿈이 살아 있다 |
| ⬜ | 자주 묻는 질문 — 내리기 | 질문을 전부 「내림」으로 바꾸고 저장 → 고객센터에서 메뉴가 사라진다 |
| ⬜ | 자주 묻는 질문 — 실제 서버 | 위 세 줄을 QA 서버에서 한 번 더 (만들 때는 가짜 서버로 봤다) |
| ⬜ | 화면 꾸미기 — 구성 | 구역 순서를 바꾸고, 하나를 끄고, 제목을 고친다 → 오른쪽 미리보기 → 저장 → 손님 화면 |
| ⬜ | 화면 꾸미기 — 색 | 띠·헤더·푸터의 바탕과 글자를 바꿔 본다 → 「전부 기본색으로」 → 저장 |
| ⬜ | 화면 꾸미기 — 배너·상단 띠·푸터 | 탭을 옮긴 뒤에도 전처럼 저장된다 (배너 올리기, 띠 링크·아이콘, 푸터 글자) |
| ⬜ | 운영시간 (QA-080) | 푸터 탭의 운영시간·휴무를 토요일이 어느 쪽인지 알 수 있게 고친다 (예: 「토·일·공휴일 휴무」) |

## 5. 운영에 올릴 때

| | 확인 | 방법 |
|---|---|---|
| ⬜ | QA 확인이 끝났다 | 위 1~4 |
| ⬜ | `qa` → `main` 합치기 | 운영 배포는 `main` 푸시로 돈다 |
| ⬜ | 운영 결제가 실결제 그대로다 | 배포 뒤 https://api.hanseongge.com/api/v1/payments/config 의 `testMode` 가 `false`, `clientKey` 가 `live_` 로 시작 |
| ⬜ | 운영 화면 | 메인·시세·상품 상세·푸터 로고, 휴대폰 검색 |
| ⬜ | 자주 묻는 질문을 적는다 | 운영 관리자에서 실제 질문을 적기 전까지 고객센터에 메뉴가 뜨지 않는다 |
| ⬜ | 데이터 손보기 | 백금 매입가(90,000원 — 입력 오류로 보인다), 상단 띠의 인스타그램 링크가 공식 계정인지, 시세 고시가 멈춰 있지 않은지 |
